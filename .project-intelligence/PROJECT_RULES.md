# Initial Project Safety Rules

- This inventory was generated by Stage 1. It is not a verified architecture description.
- Preserve existing source files and Git working-tree changes.
- Write generated project knowledge under `.project-intelligence` only.
- Do not assume a file exists in production or that its feature works just because it exists in the repository.
- Check the README, PRD, AGENTS.md, manifests, and tests before making implementation claims.
- Secret-file names, common binary types, lockfiles, large files, build outputs, dependencies, caches, and log folders are excluded by the current scanner filters. These rules are broad defaults and may need tuning for unusual repositories.
- The scanner does not run code or tests.
